# 🧠 Knowledge Quiz

A per-level knowledge quiz for a club: ten questions each at Beginner, Intermediate and Expert, with an explanation on a wrong answer and a total score. Signed-in readers save their attempt and the club shows global stats. Ships a built-in Cryptography set; a curator can supply their own questions in config.

> **Reference mirror.** This folder is a read-only mirror of a club add-on that ships in
> the [ilm.red](https://ilm.red) monorepo. It is generated by a job — **do not edit here.**
> It won't build standalone (it imports the app's `@/…` modules); it's published so you can

## What it does

A **tab** add-on: it renders in a club "Quiz" section. Questions come from `book_club_addons.config.levels` when a curator sets them, otherwise the built-in Cryptography set. On completion a signed-in reader's attempt is recorded via `record_quiz_attempt` and the level's global stats are shown; signed-out readers see the read-only aggregates via `club_quiz_stats`. The `@/…` imports in the source stay unresolved here — the folder is a reference showcase, not a standalone build.

## Registration (the contract)

A club add-on is two things that must agree: a row in `addon_registry` **and** one entry in
`ADDON_MANIFEST` (`src/components/addons/index.ts`), keyed by the same `entry_point`:

```ts
{ slug: 'club-quiz', entryPoint: 'ClubQuizAddon', placement: 'tab' }
```

The genericized registry INSERT and the schema it reads are in [`club-quiz.sql`](./club-quiz.sql).

## Privacy

Runs in your browser. When you are signed in, your result (level, score, total) is saved so the club can show aggregate stats (attempts, averages); individual answers are never stored. Signed-out readers see only the aggregates.
