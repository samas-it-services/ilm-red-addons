# 💬 Welcome Message

Display customizable welcome messages to new and existing members. Include club stats, upcoming events, and personalized greetings.

> **Reference mirror.** This folder is a read-only mirror of a club add-on that ships in
> the [ilm.red](https://ilm.red) monorepo. It is generated by a job — **do not edit here.**
> It won't build standalone (it imports the app's `@/…` modules); it's published so you can
> read exactly how a real add-on is built, registered and wired.

## What it does

A built-in **decoration** add-on: it renders through the Overview welcome block (self-gated on the slug), not through `<AddonSlot>`. Built-ins are auto-installed and enabled in every club by the `auto_install_builtin_addons` trigger, so the enablement SQL below is informational.

## Registration (the contract)

A club add-on is two things that must agree: a row in `addon_registry` **and** one entry in
`ADDON_MANIFEST` (`src/components/addons/index.ts`), keyed by the same `entry_point`:

```ts
{ slug: 'welcome-message', entryPoint: 'WelcomeMessageAddon', placement: 'decoration' }
```

The genericized registry INSERT and the schema it reads are in [`welcome-message.sql`](./welcome-message.sql).

## Configuration

- `title` (string, default `"Welcome to our Book Club! 📚"`) — Welcome Title
- `enabled` (boolean, default `true`) — Enable Welcome Message
- `message` (string, default `"We are excited to have you here!"`) — Welcome Message
- `dismissible` (boolean, default `true`) — Allow Dismissal
- `showToAllMembers` (boolean, default `false`) — Show to All Members
- `showToNewMembers` (boolean, default `true`) — Show to New Members
- `showBookClubStats` (boolean, default `true`) — Show Club Statistics
- `showUpcomingEvents` (boolean, default `true`) — Show Upcoming Events
