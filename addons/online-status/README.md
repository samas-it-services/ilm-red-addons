# 👥 Online Status

Track and display member online status with privacy controls. See who is active, idle, or offline in real-time.

## What it does

A built-in **decoration** add-on: it decorates the Members list through the `useClubPresence` hook (self-gated on the slug), reading live realtime presence and honouring each member's `presence_hidden` flag. Built-ins are auto-installed and enabled in every club.

## Registration (the contract)

A club add-on is two things that must agree: a row in `addon_registry` **and** one entry in
`ADDON_MANIFEST` (`src/components/addons/index.ts`), keyed by the same `entry_point`:

```ts
{ slug: 'online-status', entryPoint: 'OnlineStatusAddon', placement: 'decoration' }
```

The genericized registry INSERT and the schema it reads are in [`online-status.sql`](./online-status.sql).

## Configuration

- `enabled` (boolean, default `true`) — Enable Status Tracking
- `showLastSeen` (boolean, default `true`) — Show Last Seen
- `groupByStatus` (boolean, default `true`) — Group by Status
- `showOnlineCount` (boolean, default `true`) — Show Online Count
- `allowPrivateMode` (boolean, default `true`) — Allow Private Mode
- `autoOfflineMinutes` (number, default `15`) — Auto-offline Timeout (minutes)
- `showActivityStatus` (boolean, default `true`) — Show Activity Status

## Privacy

Shows which members are currently active. Your online status is visible to other members of this club while you browse it; it is never shared outside the club.
