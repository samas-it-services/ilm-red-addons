# 🔭 Physics Image of the Day

Today's astronomy & physics images from NASA APOD, NASA Image of the Day, ESO and ESA/Hubble — shown together, with a carousel to browse past days. Every image keeps its source credit and a link to the original.

## What it does

Images are fetched server-side each night into the public-read `image_of_day` table; the card reads the newest row per source plus a carousel of past days.

## Registration (the contract)

A club add-on is two things that must agree: a row in `addon_registry` **and** one entry in
`ADDON_MANIFEST` (`src/components/addons/index.ts`), keyed by the same `entry_point`:

```ts
{ slug: 'physics-image-of-day', entryPoint: 'PhysicsImageOfDayAddon', placement: 'overview', component: PhysicsImageOfDayAddon }
```

The monorepo wires it with a thin adapter mapping the standard `AddonSurfaceProps`:

```tsx
const PhysicsImageOfDayAddon = ({ clubId }) => <PhysicsImageOfDay clubId={clubId} />;
```

The genericized registry INSERT and the schema it reads are in [`physics-image-of-day.sql`](./physics-image-of-day.sql).
