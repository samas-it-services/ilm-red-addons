# 🧩 Math Puzzle of the Day

A self-contained maths puzzle each day, with a hidden answer and worked solution you can reveal. Curated bank, refreshed daily.

> **Reference mirror.** This folder is a read-only mirror of a club add-on that ships in
> the [ilm.red](https://ilm.red) monorepo. It is generated by a job — **do not edit here.**
> It won't build standalone (it imports the app's `@/…` modules); it's published so you can
> read exactly how a real add-on is built, registered and wired.

## What it does

Content is produced server-side each night (a curated pick from `daily_card_seeds`, an optional AI-written explainer) and written to `daily_cards`. This card just reads the latest row.

## Registration (the contract)

A club add-on is two things that must agree: a row in `addon_registry` **and** one entry in
`ADDON_MANIFEST` (`src/components/addons/index.ts`), keyed by the same `entry_point`:

```ts
{ slug: 'math-puzzle-of-day', entryPoint: 'MathPuzzleOfDayAddon', placement: 'overview', component: MathPuzzleOfDayAddon }
```

The monorepo wires it with a thin adapter mapping the standard `AddonSurfaceProps`:

```tsx
const MathPuzzleOfDayAddon = ({ clubId }) => <DailyContentCard clubId={clubId} slug="math-puzzle-of-day" />;
```

The genericized registry INSERT and the schema it reads are in [`math-puzzle-of-day.sql`](./math-puzzle-of-day.sql).
