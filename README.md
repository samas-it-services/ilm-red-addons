## How a club add-on works

A club add-on is **two things that must agree**: a row in the `addon_registry` table and one
entry in `ADDON_MANIFEST`, keyed by the same `entry_point`. Card add-ons render through a single
`<AddonSlot placement="…">`; "decoration" add-ons augment existing UI through a self-gated hook.
Every add-on self-gates on `useClubAddonEnabled(clubId, slug)` and runs under row-level security —
an add-on can never widen data access. See each add-on's README for its specifics.

The six "X of the Day" cards share one component, [`addons/_shared/DailyContentCard.tsx`](./addons/_shared/DailyContentCard.tsx),
instantiated with a different slug each.
